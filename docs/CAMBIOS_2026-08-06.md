# Cambios — 06/08/2026 — Lead-magnet de captación + rebrand Sinaptek

Registro de los cambios realizados el día 06/08/2026. Rama: `feature/lead-magnet/sinaptik`. PR asociado: pending (CI + 1 aprobación).

## Objetivo

Convertir la aplicación en una herramienta B2B de captación de leads con **rebrand a "Sinaptek"**: simulador interactivo de precios que entrega resultados más gráfico y, tras un formulario gated, descarga de un **PDF personalizado** con `pdf-lib`. El lead queda persistido en el backend (`POST /api/v1/leads` con Prisma/SQLite).

## Gestión de dependencias (issue)

El intento de `npm dedupe` contaminó el lock root con `@angular/core@22.1.0` y dejaba una copia anidada en `apps/frontend/node_modules` (21.2.19) que rompía los tests con `NG0203`. **Solución:** se restauró el lock original, se unificó todo el árbol en **Angular 21.2.9** (una sola copia en la raíz) con `@angular/service-worker@21.2.9` fijado, y se eliminó la copia anidada.

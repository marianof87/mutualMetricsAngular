## 3. Registro de observación formal — NO posible desde este entorno

Se intentó registrar la observación formal que resumiera la arquitectura
(`core/`, `shared/` y los 13 `features/`), pero **no hay mecanismo manual de ingesta**:

| Vía intentada | Resultado |
|---|---|
| Tool MCP de escritura | No existe: las tools MCP son solo de lectura/gestión (search, build_corpus, prime, query…) |
| `POST /api/observations` (worker) con esquema `{}` | **404** |
| `POST /api/observations` con esquema completo de claude-mem (`project`, `type`, `title`, `content`) | **404** |
| `OPTIONS /api/observations` | POST permitido, pero la ruta específica no matchea |
| Viewer web (`viewer-bundle.js`) | **Solo lectura**: el único POST visible es `/api/logs/clear` |

**Conclusión:** claude-mem captura observaciones de forma **automática** a partir de
sesiones reales de agentes (hooks de opencode/Claude Code). No hay endpoint público ni
tool MCP para escribirlas a mano en este entorno.

Sobre Sinaptek

Plataforma académica desarrollada para aplicar conceptos de desarrollo Full Stack, modelado matemático y arquitectura moderna de software.

Nuestro proyecto

Sinaptek es una aplicación web que integra herramientas para la resolución de funciones cuadráticas, optimización de precios y gestión de escenarios de análisis. El proyecto fue desarrollado como parte de una propuesta académica que busca aplicar conocimientos teóricos en un entorno práctico mediante el uso de tecnologías modernas.

Objetivos

Desarrollo Full Stack

Aplicar buenas prácticas de desarrollo frontend y backend mediante una arquitectura moderna basada en Angular y NestJS.

Matemática Aplicada

Implementar herramientas que permitan resolver funciones cuadráticas y optimizar escenarios de precios y ganancias.

Trabajo Colaborativo

Fortalecer el trabajo en equipo utilizando Git, GitHub y metodologías de desarrollo colaborativo.

Contexto Académico

Sinaptek fue desarrollado como proyecto académico de la carrera Programación Full Stack de la Universidad Provincial de Córdoba.

El trabajo se realiza en el marco de la materia Programación Web, correspondiente al segundo año de la carrera, integrando conceptos de desarrollo frontend, backend, arquitectura de software, bases de datos, control de versiones y trabajo colaborativo.
